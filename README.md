# Student Performance Analysis

## Project Overview
This project analyzes the academic performance of 30 students using Python. It explores how study hours and attendance relate to students' examination marks.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset Information
The dataset contains 30 student records with the following columns:
- Student_ID
- Name
- Study_Hours
- Attendance
- Marks

## Project Features
- Dataset creation and exploration
- Statistical analysis of student marks
- Identification of top 5 performing students
- Student marks visualization
- Study hours vs marks analysis
- Attendance vs marks analysis
- Correlation analysis

## Key Analysis
- Average, highest and lowest marks
- Average study hours
- Average attendance
- Relationship between study hours, attendance and marks

## Conclusion
This project demonstrates basic data analysis and visualization skills using Python. It helps understand student performance through data-driven insights.
